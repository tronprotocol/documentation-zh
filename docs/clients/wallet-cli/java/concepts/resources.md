# 资源：带宽、能量与份额

TRON 账户通过冻结（质押）TRX 来获得资源。本页汇总各操作页面所引用的机制。

## 冻结产生的份额与带宽

资金冻结之后，会获得相应数量的份额（share）和带宽（Bandwidth）。份额可用于投票，带宽可用于交易。

- **份额（Share）**——每冻结 1 TRX 可获得 1 单位份额。份额用于[投票](../commands/vote-reward.md#how-to-vote)。
  解冻之后，此前的投票将失效。
- **带宽（Bandwidth）**——由链上交易消耗（转账、资产转移、投票、冻结等）。查询不消耗带宽。

## 如何计算带宽

一笔交易消耗的带宽等于它的**字节数**——200 字节的交易消耗 200 带宽。所有链上交易都会消耗带宽，
包括转账、资产转移、投票、冻结等；查询不消耗带宽。

质押并不会直接换来一个固定数量的带宽。你的带宽额度是**全网固定带宽池中的一份**，按你为获取带宽
所质押的 TRX 占比分配：

```text
额度 = (你为获取带宽质押的 TRX / 全网为获取带宽质押的 TRX 总额) * 全网 Bandwidth 总量
```

由于你的质押量和全网质押总额都会随时变化，这个额度**不是固定值**，它是被重新计算出来的，而不是
多次冻结逐次累加得到的。在 Stake 1.0 中，冻结天数只是锁定条件，并不参与该计算。完整模型见
[资源模型](../../../../mechanism-algorithm/resource.md)。

每个已激活账户还有一份很小的每日免费额度，它独立于质押获得的额度——注意这份免费额度不能用于
创建账户。带宽不够时，节点会从余额中燃烧 TRX 来补足差额。
