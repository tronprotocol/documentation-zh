# wallet-cli encoding

在各种格式之间转换和校验地址与编码。

一组纯本地工具，不访问节点，也不会读取或修改 keystore。

## 用法

```
wallet-cli encoding COMMAND
```

## 子命令

| 命令 | 页面 | 说明 |
|---|---|---|
| `encoding convert` | [convert.md](convert.md) | 自动识别输入，并打印它的所有等价表示 |
