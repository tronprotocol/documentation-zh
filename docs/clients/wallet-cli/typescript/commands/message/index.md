# wallet-cli message

对任意消息进行签名。

## 用法

```
wallet-cli message COMMAND
```

在 TRON 和 EVM 网络上都可运行：用账户的哪一把密钥签名由所选网络决定——TRON 密钥用 TIP-191/V2，EVM 密钥用 EIP-191——报告哪个地址也由它决定。

## 子命令

| 命令 | 页面 | 说明 |
|---|---|---|
| `message sign` | [sign.md](sign.md) | 对任意消息签名 |
