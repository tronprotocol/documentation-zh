# 指南

按任务组织的操作指引。初次接触？先看 **快速上手**，其余按需取用。除非示例本身是在演示 EVM 网络，否则都在 Nile 测试网上运行。

| 指南 | 涵盖内容 |
|---|---|
| [快速上手](getting-started.md) | 创建钱包、在 Nile 上充值、查询余额、发出第一笔交易 |
| [发送币与 token](send-tokens.md) | 发送网络原生币以及 TRC20 / ERC20 / TRC10 token；token 地址簿 |
| [质押与资源](stake-and-resources.md) | 质押、代理与解质押 TRX，以换取能量 / 带宽（TRON） |
| [使用 Ledger](ledger.md) | 注册 Ledger 硬件钱包并用它签名 |
| [脚本编写](scripting.md) | 在 shell 脚本和 CI 中安全地调用 wallet-cli |

逐条命令的细节请见[命令参考](../commands/index.md)；JSON 接口规范请见
[machine-interface](../machine-interface.md)。
