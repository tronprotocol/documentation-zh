# 核心概念

本节介绍这些链与 wallet-cli 的核心机制，帮助理解各命令的设计和行为。

| 概念 | 讲什么 |
|---|---|
| [网络](networks.md) | 规范的 CAIP-2 网络 id 及其别名、两个链家族、命令如何选择网络，以及两种费用模型 |
| [账户与 HD 钱包](accounts-and-hd.md) | 种子、派生账户、每个链家族一个地址、账户类型、当前账户，以及备份与删除 |
| [能量与带宽](energy-bandwidth.md) | TRON 的费用模型，以及 `stake` 为何存在 |
| [安全模型](security.md) | 密钥存储、敏感信息处理、恢复方式，以及哪些责任仍在你自己身上 |

需要按场景完成操作，请参见[指南](../guide/index.md)；需要查询具体命令，请参见
[命令参考](../commands/index.md)。
