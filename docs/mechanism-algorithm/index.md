# 理解 TRON 协议

涵盖 TRON 共识、超级代表、账户与签名、网络资源、系统合约和账户权限的文档。

## 推荐阅读顺序

1. [DPoS 共识](dpos.md) — 共识概念、区块生产与固化、超级代表选举、激励机制和基于提案的参数变更。
2. [超级代表](sr.md) — 超级代表参选与选举、出块和投票奖励以及委员会提案操作。
3. [账户模型](account.md) — 账户创建与激活、密钥对和地址生成以及签名的创建与验证。
4. [资源模型](resource.md) — TRON Power、Bandwidth、Energy 与 `fee_limit`、动态 Energy、质押、资源代理、解质押和资源 API。
5. [系统合约](system-contracts.md) — java-tron 系统合约的 `ContractType` 概览和 protobuf 字段。
6. [账户权限管理](multi-signatures.md) — 权限级别与结构、费用与限制、更新和签名流程、辅助接口及示例。
