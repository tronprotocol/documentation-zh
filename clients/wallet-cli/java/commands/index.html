    命令参考¶

    命令按功能分组到以下页面；A–Z 索引可直接跳转到每条命令所在的章节。

    在交互式钱包中执行 help <command> 即可看到该命令内置的用法提示；单独执行 help 会打印完整的命令表。只输入命令名并不一定会显示用法——大多数无需参数的命令会直接执行。
